# GoTypist
---

Author: **KERNL**

Insipired from [MonkeyType](https://monkeytype.com/)'s simple UI and the core mechanics of testing your ability to type quick and efficiently. I have never touched Go before so this is my first Go project! The goal is simple, build a barebones working version of a typing test and see how Go works on the Go (nice joke).

This project is submitted for [GoShip](https://goship.hackclub.com/)!

# How it works
---
The main file `main.go` loads a pre-defined wordlist `wordlist.txt` and picks out random words depending to the chosen length of words to be typed. (ex. 25 Words -> 25 Random words).

There are also difficulty to be selected: Easy, Normal, Hard. The difficulty dictates which words shall be picked based on their length and complexity of spelling, the words are categorized into the words length.
